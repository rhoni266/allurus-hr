Design system

One set of tokens and reusable components behind every screen, for every role. Change the theme or accent here and see every component follow.

Open the appBrand kit

Colour tokens

Semantic tokens, never raw colours. Each has a light and a dark value. Status colours always come with a text label, so colour is never the only signal.

Accent themes

People pick their own accent in Settings → Appearance. Each accent has a light and dark value checked for at least 4.5:1 contrast with button text.

Spacing, density and motion

--card-pad, --gap, --cell-y and --ctl-h drive spacing; the compact density swaps them for smaller values. Motion uses --ease and --dur, and is switched off when someone asks for reduced motion.

Buttons

One primary action per area. Icon-only buttons always have an accessible label.

Principles

Human first

Write like a helpful colleague. Greet people, celebrate wins, and nudge gently about rest and money.

Accessible by default

Keyboard paths for everything, visible focus, labelled icons, 4.5:1 text contrast, and respect for reduced motion.

One system

Build new screens from these tokens and components. If something is missing, add it here first.
